# House Prices

Kaggle House Prices 데이터셋으로 주택 판매가를 예측하는 회귀 실습입니다. 노트북과 Python 파일에는 데이터 탐색 및 실험 코드가 포함되어 있습니다.

## Files

- `Untitled.ipynb`: 데이터 탐색 노트북
- `untitled.py`, `untitled1.py`: 별도 모델링·특성 엔지니어링 실습 코드
- `train.csv`, `test.csv`, `data_description.txt`: 대회 제공 데이터와 설명
- `submission.csv`: 생성한 제출 파일

데이터 출처: [Kaggle House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)
