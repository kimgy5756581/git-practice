## Reproducibility and scope

- 대회 데이터, 모델 가중치, 제출 ZIP, 인증 정보, 생성 로그는 포함하지 않습니다.
- 각 프로젝트 README에 실행 조건과 결과의 해석 범위를 명시합니다. 특히 로컬 리그 결과는 Kaggle 리더보드 성과의 대체 증거가 아닙니다.
- 외부 데이터는 해당 대회의 이용 약관을 따릅니다.
