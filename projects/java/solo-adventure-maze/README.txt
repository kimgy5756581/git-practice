=====================================================================
 Solo Adventure Maze  -  텍스트 기반 미로 탐험 게임 (Java)
 과목: Computer Language (ITM413) 기말 프로젝트
=====================================================================

[ 폴더 구조 ]
  SoloAdventureMaze/
   ├─ itm/comlang/*.java   ... 소스 22개 (한 파일에 public 클래스 하나)
   ├─ start.csv            ... 시작 방 (이름 고정)
   ├─ room2.csv ~ room4.csv... 그 외 방들
   └─ README.txt           ... 이 파일
  실행하면 run_<숫자>/ 폴더가 자동 생성됩니다(원본 복사본, 원본은 안 바뀜).

[ 컴파일 & 실행 ]   ※ start.csv 가 있는 이 폴더에서 실행하세요.
  javac itm/comlang/*.java
  java  itm.comlang.Main

[ 조작법 ]
  u / d / l / r : 위 / 아래 / 왼쪽 / 오른쪽 이동
  a            : 인접한 몬스터 공격
  q            : 종료
  (잘못된 키를 눌러도 프로그램은 멈추지 않고 안내만 합니다.)

[ 목표 ]
  무기를 모아 몬스터를 처치하고, 트롤(T)을 잡으면 떨어지는 열쇠(*)를 주워서
  마스터 문(D)으로 탈출하면 승리합니다.

[ 칸 기호 ]
  S/W/X = 막대기/약한검/강한검 (공격력 1/2/3)
  G/O/T = 고블린/오크/트롤 (HP 3/8/15),  m/B = 작은물약/큰물약 (+6/+12)
  d:파일명 = 일반 문,  D = 마스터 문,  * = 열쇠

[ 참고 ]
  - 자세한 코드 설명은 함께 제출한 PDF 문서를 보세요.
  - 모든 경로는 상대 경로이며, 원본 CSV는 복사본만 수정되어 보존됩니다.
