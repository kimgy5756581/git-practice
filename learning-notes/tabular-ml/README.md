# Tabular ML Notes

표 형식 데이터에서 전처리와 모델 비교를 연습한 자료입니다.

- `hands-on-tabular-ml.ipynb`: Tabular ML 실습 노트북
- `magic-gamma-classification.ipynb`: MAGIC Gamma Telescope 데이터 분류 실험
- `study-notes.txt`: 실습 과정에서 정리한 메모

노트북에는 `scikit-learn`, XGBoost, TabPFN, Hugging Face Transformers 등 실험별 추가 라이브러리가 사용됩니다. 실행 전 해당 노트북의 설치 셀과 GPU 요구 사항을 확인하세요.
